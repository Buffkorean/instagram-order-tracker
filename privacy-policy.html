Privacy Policy

Live Order Tracker Chrome Extension — Last updated: July 2026

Overview

Live Order Tracker ("the Extension") is a Chrome browser extension that helps Instagram Live sellers capture and organize product orders from the live comment feed. This policy explains what data the Extension accesses and how it is handled.

Data the Extension Accesses

  • Instagram Live comment text and usernames — read directly from the Instagram page open in your browser to identify order comments.
  • Your payment link — a URL you optionally type into the Settings tab (e.g., Venmo or PayPal link).
  • Microphone audio — only if you turn on the optional "🎙 Auto-detect" feature. It is off by default. See "Auto-detect (Microphone) Feature" below.

How Data Is Stored

Order data and settings are stored locally in your browser only using chrome.storage.local. This includes:

  • Captured order details (username, size, color, quantity, timestamp, original comment)
  • Your payment link (if entered)
  • Your backend API key (if you enable Auto-detect)

This data is never transmitted anywhere except as described in "Auto-detect (Microphone) Feature" below — order comment data itself always stays on your device.

Auto-detect (Microphone) Feature

Auto-detect is an optional, off-by-default feature. If you turn it on, the extension:

  • Requests microphone access (Chrome will prompt you to allow this the first time)
  • Records short (~20 second) rolling audio clips of you describing items during your live
  • Sends each clip to our backend server, which forwards it to Groq for speech-to-text transcription and to Anthropic (Claude) to identify what item is being described
  • Uses the result to auto-fill the "Now Selling" item name and price

Audio clips and transcripts are processed in real time and are not stored by our backend server after a response is returned. Groq and Anthropic process this data as sub-processors under their own privacy policies (Groq's Privacy Policy, Anthropic's Privacy Policy) and may retain it briefly per those policies (e.g., for abuse monitoring). This feature requires a backend API key that only the extension's distributor can issue — it will not function without one.

Analytics

The extension collects anonymous, aggregated usage data via Google Analytics to help us understand how the extension is used and improve it. This includes:

  • When the extension popup is opened
  • When the Excel export is downloaded (total order count only)
  • When a new session is started

No personally identifiable information is collected through analytics. Instagram usernames, comment text, order details, and payment links are never sent to analytics. Google Analytics may associate your data with an approximate location (country level) based on IP address. See Google's Privacy Policy for details.

Data Sharing

We do not sell or rent any data. Anonymous usage data is shared with Google Analytics as described above. If you enable Auto-detect, audio clips are shared with Groq and Anthropic solely to power that feature, as described above. No other third parties receive any data from this extension.

Data Retention

Order data remains in local storage until you click "New Session" in the extension popup, which clears it. Uninstalling the extension also removes all stored data. Audio clips sent for Auto-detect are not retained by our backend server after processing.

Permissions Used

  • storage — to save captured orders, settings, and your payment link locally in the browser.
  • windows — to support the "Pop Out" feature that opens the popup in a separate window.
  • offscreen — to run microphone capture in the background while Auto-detect is on. Only used if you enable that feature.
  • instagram.com host permission — to read the live comment feed on Instagram pages so orders can be captured in real time. No data from Instagram is sent anywhere.
  • speaksuccess.kr host permission — used only when Auto-detect is on, to send audio clips to our backend for processing as described above.

Children's Privacy

This extension is intended for adult business use only and is not directed at children under 13.
